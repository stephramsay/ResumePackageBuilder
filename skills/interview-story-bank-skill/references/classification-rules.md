# Classification Rules

Use semantic judgment after deterministic extraction. The script can register files, hash them, extract text, and generate templates; Codex must decide the narrative relationship.

## Duplicate

Classify as `duplicate` when the new material has the same:

- situation or project
- Stephanie role
- core actions
- outcome or lesson
- usable interview angle

Do not add duplicates. Add the source reference to the existing story only if it improves evidence quality.

## Meaningful Variation

Classify as `meaningful_variation` when the broad project is the same but the interview use is genuinely different, such as:

- different stakeholder or audience
- different conflict, constraint, or tradeoff
- different metric or outcome
- different question type
- different lesson learned
- different scale or market framing
- different role-level framing, for example IC execution vs executive strategy

Create a variation only when it can stand alone in an interview without feeling like the same answer repeated.

## New Angle

Classify as `new_angle` when the story is not new, but the document adds:

- a stronger bridge to a role or sector
- new question wording
- a clearer principle layer
- a backup route for a common behavioral question
- better phrasing in Stephanie's voice

Attach the angle to the existing story or question route; do not create a new story.

## New Story

Classify as `new_story` when the situation, action, result, or lesson is materially new. A new story should have enough factual detail to support at least a concise STAR answer.

If it is promising but thin, mark it `needs_review` and ask Stephanie for the missing details.

## Source Only

Classify as `source_only` when the material contains useful evidence, claims, metrics, job framing, or role language, but no reusable interview narrative.

## Safety

Never promote stories from placeholders, speculation, or role-specific hypotheticals as canonical facts. Keep patient/user research media metadata-only unless Stephanie explicitly asks to transcribe or mine it.
