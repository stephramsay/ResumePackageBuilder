# Report Format

Use this structure for candidate reports and discovery passes.

```markdown
# Story Bank Scan Report - YYYY-MM-DD

## Summary

- Input:
- Sources scanned:
- Canonical stories added:
- Meaningful variations proposed:
- New angles proposed:
- Duplicates skipped:
- Needs Stephanie review:

## Added Or Proposed Stories

### STORY_ID_OR_CANDIDATE_LABEL

- Classification:
- Existing story relationship:
- Why it is or is not unique:
- Best themes:
- Best question types:
- Evidence:
- Recommended action:

## Variations

## New Angles

## Duplicates Not Added

## Source-Only Evidence

## Needs Stephanie Review

## Next Actions
```

Always include plain-English reasoning. The report should be useful even if Stephanie never opens the YAML.
